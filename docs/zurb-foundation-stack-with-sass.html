Zurb Foundation Stack With Sass

Permalink: 2014-08-07 14:48:00-05:00 by chris in Technology tags: compass foundation rwd sass zurb

I'll put this here so I don't lose it ;-) Here are the programs I installed that allowed me to create a Foundation 5 project using their Sass (and other) files. I'm running Windows 7 Enterprise (64 bit). --- These require Windows administrator rights --- Ruby (1.9+) for Windows (I got version 1.9.3) I used Installed to C:\Ruby193\bin\ruby.exe Git for Windows Installed to C:\Users\user-name]\AppData\Local\Programs\Git\cmd\git.exe GitHub for Windows Node.js (I got version 0.10.29) http://nodejs.org/ This also installs npm. Installed to C:\Program Files (x86)\nodejs\node.exe You might need to create the 'npm' folder in C:\Users\user-name]\AppData\Roaming\ to be able to use npm. --- These require npm --- Yeoman (I got version 1.2.1) Installed to C:\Users\user-name]\AppData\Roaming\npm\yo Grunt (I got version 0.1.13) Installed to C:\Users\user-name]\AppData\Roaming\npm\grunt Bower (I got version 1.3.12) Installed to C:\Users\user-name]\AppData\Roaming\npm\bower --- These require Ruby --- Sass (I got version 3.3.14) Installed to C:\Ruby193\bin\sass Compass (I got version 0.12.7) Installed to C:\Ruby193\bin\compass Foundation w/ Sass (I got version 1.0.4) Installed to C:\Ruby193\bin\foundation
